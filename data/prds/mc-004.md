# PRD: Mostrar roadmap de Obsidian en vista de proyecto

## Task ID
mc-004

## Objetivo
Cuando existe un archivo `data/scans/{slug}-obsidian.json` para un proyecto, mostrar su roadmap (tareas de Obsidian) en la página de detalle del proyecto (`app/project/[slug]/page.tsx`).

## Contexto
- `toolbox/sync-obsidian.sh` genera archivos en `data/scans/{slug}-obsidian.json`
- Cada archivo tiene esta estructura:
```json
{
  "projectId": "carApp",
  "sourceFile": "/home/francisco/Documents/Obsidian Vault/carApp.md",
  "tasks": [
    { "title": "Tarea pendiente", "status": "pending", "source": "obsidian" },
    { "title": "Tarea completa", "status": "done", "source": "obsidian" }
  ]
}
```
- La vista de proyecto ya existe en `app/project/[slug]/page.tsx`
- Los componentes existentes usan CSS inline con variables de `globals.css`
- La estética es Terminal RPG (fuente Press Start 2P, colores oscuros, bordes pixel)

## Archivos a modificar

### 1. `lib/data.ts` — Agregar función de lectura
```typescript
export interface ObsidianRoadmap {
  projectId: string;
  sourceFile: string;
  tasks: Array<{
    title: string;
    status: "pending" | "done";
    source: "obsidian";
  }>;
}

export async function getObsidianRoadmap(
  slug: string,
): Promise<ObsidianRoadmap | null> {
  const filePath = join(DATA_DIR, "scans", `${slug}-obsidian.json`);
  try {
    const raw = await readFile(filePath, "utf-8");
    return JSON.parse(raw);
  } catch {
    return null;
  }
}
```

### 2. `components/RoadmapPanel.tsx` — Crear componente nuevo
- Componente server (no necesita "use client")
- Recibe `ObsidianRoadmap` como prop
- Muestra lista de tareas con checkmarks visuales
- Tareas done: texto tachado, opacidad 0.5, icono ●
- Tareas pending: icono ○
- Header con conteo: "3/8 completed"
- Usar `Panel` existente con title="Obsidian Roadmap"
- Fuente y colores consistentes con el resto del dashboard

### 3. `app/project/[slug]/page.tsx` — Integrar el panel
- Importar `getObsidianRoadmap` y `RoadmapPanel`
- Llamar `getObsidianRoadmap(slug)` en la función del page
- Si existe roadmap, renderizar `<RoadmapPanel>` después del panel de Quests
- Si no existe, no renderizar nada (sin mensaje de error)
