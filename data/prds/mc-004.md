# PRD: Mostrar roadmap de Obsidian en vista de proyecto

## Task ID
mc-004

## Objetivo
Cuando existe un archivo `data/scans/{slug}-obsidian.json` para un proyecto, mostrar su roadmap en la página de detalle del proyecto.

## Contexto
Proyecto: missionControl
El script `toolbox/sync-obsidian.sh` genera archivos JSON con roadmaps extraídos de Obsidian.

Estructura del JSON:
```json
{
  "projectId": "carApp",
  "sourceFile": "/path/to/note.md",
  "tasks": [
    { "title": "Tarea pendiente", "status": "pending", "source": "obsidian" },
    { "title": "Tarea completa", "status": "done", "source": "obsidian" }
  ]
}
```

## Archivos a modificar

- `lib/data.ts` — agregar interface y función de lectura
- `components/RoadmapPanel.tsx` — crear componente nuevo
- `app/project/[slug]/page.tsx` — integrar el panel

## Instrucciones

### 1. En `lib/data.ts` agregar:

```typescript
export interface ObsidianRoadmap {
  projectId: string;
  sourceFile: string;
  tasks: Array<{
    title: string;
    status: "pending" | "done";
    source: "obsidian";
  }>;
}

export async function getObsidianRoadmap(
  slug: string,
): Promise<ObsidianRoadmap | null> {
  const filePath = join(DATA_DIR, "scans", `${slug}-obsidian.json`);
  try {
    const raw = await readFile(filePath, "utf-8");
    return JSON.parse(raw);
  } catch {
    return null;
  }
}
```

### 2. Crear `components/RoadmapPanel.tsx`:

- Named export: `export function RoadmapPanel`
- Props interface: `{ roadmap: ObsidianRoadmap }`
- Import `Panel` from `@/components/Panel` and wrap content with `<Panel title="Obsidian Roadmap">`
- Header line showing progress: `"3/8 completed"` in `var(--text-dim)`, fontSize 8px
- List of tasks using `<div>` rows (not `<ul>/<li>`)
- Done tasks: icon `●` in `var(--health-green)`, title with `textDecoration: "line-through"`, opacity 0.5
- Pending tasks: icon `○` in `var(--text-dim)`
- Row style: fontSize 8px, padding `4px 0`, display flex, gap 8px
- This is a server component — NO `"use client"`

### 3. In `app/project/[slug]/page.tsx`:

- Add import: `import { getObsidianRoadmap } from "@/lib/data"` and `import { RoadmapPanel } from "@/components/RoadmapPanel"`
- In the page function, call: `const roadmap = await getObsidianRoadmap(slug);`
- After the Quests panel, add: `{roadmap && <RoadmapPanel roadmap={roadmap} />}`
- Do NOT rewrite the entire file — only add these 3 things

## Criterio de éxito
- If `data/scans/missionControl-obsidian.json` exists, the roadmap panel appears
- If the file doesn't exist, the page looks unchanged
- Visual style matches existing panels
- No TypeScript errors
