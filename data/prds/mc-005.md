# PRD: Kanban board en página de Tasks

## Task ID
mc-005

## Objetivo
Rediseñar la página `/tasks` como un Kanban board con 3 columnas (Pending, In Progress, Done) donde las tareas se muestran como cards y se mueven visualmente entre columnas al cambiar de estado.

## Contexto
Proyecto: missionControl
La página actual muestra tareas en listas verticales agrupadas por estado. El diseño tipo Kanban (Jira/Linear) da mejor visibilidad del flujo de trabajo.

## Archivos a modificar

- `components/TaskBoard.tsx` — reescribir como Kanban de 3 columnas
- `app/tasks/page.tsx` — ajustar stats si es necesario

## Instrucciones

### 1. Reescribir `components/TaskBoard.tsx` como Kanban

Layout de 3 columnas:
```
┌─────────────┐ ┌─────────────┐ ┌─────────────┐
│  ○ PENDING  │ │ ◐ WORKING   │ │ ● DONE      │
│  (count)    │ │  (count)    │ │  (count)    │
├─────────────┤ ├─────────────┤ ├─────────────┤
│ ┌─────────┐ │ │ ┌─────────┐ │ │ ┌─────────┐ │
│ │ Task    │ │ │ │ Task    │ │ │ │ Task    │ │
│ │ card    │ │ │ │ card    │ │ │ │ card    │ │
│ └─────────┘ │ │ └─────────┘ │ │ └─────────┘ │
│ ┌─────────┐ │ │             │ │ ┌─────────┐ │
│ │ Task    │ │ │             │ │ │ Task    │ │
│ │ card    │ │ │             │ │ │ card    │ │
│ └─────────┘ │ │             │ │ └─────────┘ │
└─────────────┘ └─────────────┘ └─────────────┘
```

**Columnas:**
- Grid de 3 columnas iguales: `gridTemplateColumns: "1fr 1fr 1fr"`, gap 16px
- Cada columna: fondo `var(--bg-panel)`, borde 2px `var(--border)`, padding 12px
- Header de columna: icono + label en `var(--font-display)` fontSize `var(--fs-xs)`, uppercase, letterSpacing 2
  - Pending: `○ PENDING` en `var(--text-dim)`, conteo en badge
  - In Progress: `◐ WORKING` en `var(--health-yellow)`, conteo, pulse animation
  - Done: `● DONE` en `var(--health-green)`, conteo
- Conteo: badge numérico al lado del label

**Task cards (dentro de cada columna):**
- Fondo `var(--bg-dark)`, borde 1px `var(--border)`, padding 12px, marginBottom 8px
- Barra superior 2px con color del proyecto (usar hash del projectId para asignar colores consistentes)
- Línea 1: nombre del proyecto como tag (link a `/project/{slug}`) en `var(--accent)`, fontSize `var(--fs-tiny)`
- Línea 2: título de la tarea en `var(--font-body)` fontSize `var(--ft-base)`, color `var(--text)`
- Línea 3: badges de prioridad + botones PRD/Review/Start según corresponda
- Para tareas done: opacity 0.6, título con line-through

**Filtros:**
- Mantener la fila de filtros por proyecto arriba del board
- Filtro activo resaltado con `var(--accent)`

**Botones en cards:**
- `▸ Start` solo en columna Pending (borderColor green)
- `📋 PRD` si hay PRD disponible
- `📄 Review` si hay agent completed

**PRD expandido:**
- Al hacer click en PRD, mostrar debajo de la card (no modal)
- Mismo estilo que el actual: borde izquierdo 3px accent, fondo dark

### 2. Ajustes en `app/tasks/page.tsx`

- Mantener los stats arriba (Pending, In Progress, Done, With PRD)
- Pasar los mismos props al nuevo TaskBoard

## Restricciones
- NO drag and drop (complejidad innecesaria, el estado lo controla el agente)
- NO scroll horizontal — las 3 columnas deben caber en la pantalla
- Cada columna hace scroll vertical independiente si tiene muchas tareas
- Usar CSS variables del design system (no colores hardcoded)
- Usar `Icon` component para iconos, no emoji

## Criterio de éxito
- Las 3 columnas se ven claramente con sus headers
- Las tareas aparecen en la columna correcta según su status
- Al hacer Start, la tarea se mueve a la columna Working
- Al completar un agente, la tarea se mueve a Done
- Filtros por proyecto funcionan
- PRD expandible funciona dentro de las cards
- Review modal funciona desde las cards
- Responsive: si la pantalla es muy estrecha, las columnas se stackean
