# PRD: Sistema de cola visual — comandos pendientes para Qwen

## Task ID
mc-002

## Objetivo
Mostrar una lista visual de comandos/tareas en cola esperando ser ejecutados por agentes. Cuando el usuario hace Start en varias tareas, la cola muestra el orden de ejecución.

## Contexto
Proyecto: missionControl
Actualmente al hacer Start se lanza `run-agent.sh` inmediatamente. No hay forma de ver qué tareas están en cola esperando. Si se lanzan varias, se ejecutan en paralelo sin visibilidad.

## Archivos a modificar

- `components/AgentQueue.tsx` — crear componente nuevo
- `components/Sidebar.tsx` — integrar la cola debajo de la sección Agents
- `lib/data.ts` — agregar función para obtener agentes por status

## Instrucciones

### 1. Crear `components/AgentQueue.tsx`

- Named export: `export function AgentQueue`
- Props: `{ agents: AgentSession[] }` — recibe agentes con status "spawning"
- Muestra una lista vertical de agentes en cola
- Cada item muestra: posición en cola (1, 2, 3...), taskId, agentType, tiempo en cola
- Estilo: fondo `var(--bg-dark)`, borde izquierdo 2px `var(--agent-qwen)`, padding 8px
- Texto: `var(--font-body)` fontSize `var(--ft-sm)`, color `var(--text-dim)`
- Si la cola está vacía, no renderizar nada (return null)
- Usar `Icon` component con name="zap" para el indicador

### 2. En `components/Sidebar.tsx`

- Importar `AgentQueue`
- Renderizar `<AgentQueue agents={agents} />` dentro de la sección Agents, después de los agentes activos y antes de los recientes
- Solo mostrar si hay agentes en "spawning"

### 3. En `lib/data.ts`

- Agregar: `export async function getQueuedAgents(): Promise<AgentSession[]>`
- Filtra agentes con status "spawning", ordenados por startedAt ascendente

## Criterio de éxito
- Al hacer Start en 2+ tareas, la sidebar muestra la cola con orden
- Agentes activos siguen apareciendo separados arriba
- Cola desaparece cuando no hay agentes en spawning
- Sin errores de TypeScript
