# PRD: Feedback visual del estado de ejecución de agente

## Task ID
mc-003

## Objetivo
Mejorar la visualización de agentes activos con feedback en tiempo real: tiempo transcurrido, estado del modelo, y progreso visual.

## Contexto
Proyecto: missionControl
Actualmente el AgentBadge muestra solo el tipo de agente y su status (SPAWNING/WORKING/DONE/FAILED). No hay indicación de cuánto lleva trabajando, si Ollama respondió, o progreso.

## Archivos a modificar

- `components/AgentBadge.tsx` — agregar elapsed time y estados mejorados
- `app/api/agents/route.ts` — incluir timestamp para calcular elapsed

## Instrucciones

### 1. Actualizar `components/AgentBadge.tsx`

Agregar al badge existente:
- **Elapsed time**: mostrar tiempo transcurrido desde `startedAt` (ej: "12s", "1m 34s")
  - Usar `useState` + `useEffect` con intervalo de 1s para actualizar solo cuando isActive
  - Formato: segundos si <60, "Xm Ys" si >=60
  - Estilo: `var(--font-body)`, fontSize `var(--ft-sm)`, color `var(--text-dim)`
  - Posición: después del status label, separado por `·`

- **Status visual mejorado**:
  - spawning: dot blinks con `blink 0.8s step-end infinite`, label "SPAWNING" blinks
  - active: dot pulses con `pulse 1.5s infinite`, label "WORKING" en color del agente
  - completed: dot sólido sin animación, label "DONE" en `var(--health-green)`
  - failed: dot en `var(--health-red)`, label "FAILED" en rojo

- Limpiar el intervalo en el cleanup del useEffect

### 2. En `app/api/agents/route.ts`

- Ya incluye `startedAt` — verificar que se envía correctamente
- No requiere cambios si el campo ya existe

## Criterio de éxito
- Agentes activos muestran tiempo transcurrido actualizado cada segundo
- El timer se detiene cuando el agente completa o falla
- Las animaciones corresponden al estado correcto
- Sin memory leaks (interval limpiado)
- Sin errores de TypeScript
